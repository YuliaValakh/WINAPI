# C++ WinAPI Desktop Application

A native Windows desktop application written in C++ using WinAPI.

## Features
* Top menu bar with dropdown items.
* Interactive UI controls: static text, multi-line edit control, and a "CLEAR" button.


## Tech Stack
* Language: C++
* Framework: WinAPI (Windows API)
